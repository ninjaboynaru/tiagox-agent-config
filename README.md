# tiagox-agent-config

This package moved. Its skills now live in the `agent-config-skills` plugin of the [tiagox-claude-code-mods](https://github.com/ninjaboynaru/tiagox-claude-code-mods/tree/main/plugins/agent-config-skills) marketplace.

## Install

```sh
claude plugin marketplace add ninjaboynaru/tiagox-claude-code-mods
claude plugin install agent-config-skills@tiagox-claude-code-mods
```
